# 🎉 NURO PARTY

폰 하나씩 들고 모이면 끝! **설치 없이 웹에서 바로 하는 친구 파티게임**

👉 **플레이: https://nuroplay1758-boop.github.io/nuro-party/**

## 하는 법

1. 한 명이 **방 만들기** → 4자리 코드가 나와요
2. 친구들은 **초대 링크**를 받거나, **QR 코드**를 찍거나, 코드를 입력해서 참가
3. 방장이 게임을 골라서 시작!

- 📱 각자 자기 폰으로 플레이 (2~12명)
- 🌐 같은 와이파이가 아니어도 OK (LTE/5G 끼리도 연결)
- 🏆 게임을 바꿔도 점수가 계속 누적돼요

## 게임

| 게임 | 인원 | 설명 |
|---|---|---|
| 🕵️ **라이어 게임** | 3명+ | 한 명만 제시어를 몰라요. 돌아가며 한 마디씩 설명하고 투표로 라이어를 찾아요. 잡힌 라이어가 제시어를 맞히면 역전승! **🤪 바보 모드**에선 라이어도 가짜 제시어를 받아서 자기가 라이어인 줄 몰라요. |
| 👀 **눈치 게임** | 2명+ | 1부터 인원수까지 한 명씩 터치! 동시에 누르면 둘 다 탈락, 끝까지 못 누르면 탈락, 시작 전에 누르면 부정출발. |
| 🧠 **이심전심** | 2명+ | 같은 질문에 각자 답을 쓰고, 같은 답을 쓴 사람끼리 점수를 나눠요. 전원 일치하면 보너스! |
| 💣 **초성 폭탄** | 2명+ | 초성(예: ㄱㅅ)에 맞는 단어를 쓰면 폭탄이 랜덤한 사람에게 넘어가요. 언제 터질지는 아무도 몰라요. |

## 팁

- 👑 **방장 폰이 꺼지면 방이 닫혀요.** 방장은 화면을 켜 두세요 (지원 브라우저에선 자동으로 화면 꺼짐을 막아요).
- 다른 사람은 연결이 끊겨도 **다시 연결** 버튼으로 점수 그대로 복귀할 수 있어요.
- 진동·효과음이 있어요. 소리는 상단 🔊 버튼으로 끌 수 있어요.

## 기술

- 순수 HTML/CSS/JS, 빌드 없음 · GitHub Pages로 호스팅
- [PeerJS](https://peerjs.com/) (WebRTC)로 폰끼리 직접 연결 — 별도 게임 서버 없음
- 방장 폰이 게임 상태를 관리하고(host-authoritative), 비밀 정보(라이어, 답안, 폭탄 시간)는 방장 폰 밖으로 나가지 않아요

```
index.html   화면 뼈대
style.css    디자인
app.js       네트워크 · 게임 로직 · 화면
data.js      제시어 · 질문 · 초성 목록
```

로컬 실행: 폴더에서 `python -m http.server` 후 http://localhost:8000
